## What the share row does now

Four buttons, in this order, plus Text / Email / More:

```
Spread the kindness — invite someone to join!
              Share Social Media

    (TT)      (IG)      (X)      (FB)
   TikTok  Instagram    X     Facebook

  [ 💬 Text ] [ 📧 Email ] [ ↗️ More ]
```

**Each platform uses a different route, and that is deliberate.** iOS lets an app
reach another app two ways: a *URL scheme* (a link — carries text, never a file)
and a *share extension* (a real handoff — carries the file). Which one works
differs per app, and none of them accept both a picture and a caption cleanly.

| | Opens | Arrives | You paste |
|---|---|---|---|
| TikTok | direct | picture, via Photos | caption |
| Instagram | direct | picture | caption |
| X | direct | caption, already written | the picture — long-press, Paste |
| Facebook | direct | picture, attached | caption |
| Text | share sheet | card | — |
| Email | direct | card renders in the body | — |
| More | share sheet | card + caption | — |

The caption is always on the clipboard, because Instagram and TikTok have no
text API at all and Facebook refuses prefilled text by policy. X is the one
platform that accepts prefilled text, so its caption arrives typed.

**What the caption says (changed 2026-08-31).** Every share, on every channel,
now names the act being shared and then asks the reader to join:

```
My act of kindness for Day 12:
"Left a thank-you note for the mail carrier"
One kind act a day for 30 days in a row.

Join me and help make the world a kinder place. Scan the code in the picture,
or tap the link:
https://alrpa.app.link/...

#30ActsOfKindness
```

It used to open "I'm doing 30 Acts of Kindness" and never say what the act was,
so a reader could not tell what they were looking at. Text and email get the
same shape plus the written story; the certificate says all 30 are done and
names no single act, since it is not about one.

**On a story-only day the story leads instead.** Writing a story without
picking an act leaves the title as the app's placeholder, "My Story", which in
a post says nothing — the first version of this change shipped that to a live X
post. When there is no real act, the person's own words are the lead, trimmed
at a word boundary if they run past X's limit. `isRealActTitle` in
`shareMessage.js` holds the list of placeholder titles.

The act leads for a reason beyond emphasis: X caps a post at 280 characters,
and the caption is built to that cap so all four platforms get identical words.
Leading with the act instead of repeating the challenge as a sentence buys
about 40 characters — enough that every one of the 152 acts in
`acts_of_kindness.csv` fits whole. A longer title someone types themselves is
trimmed at a word boundary.

**X was rebuilt on 2026-08-31 — Gary has confirmed it, David has not.** It used to open
the system share sheet, which carries the picture and the caption together —
the best result of any platform. It was replaced because iOS alone decides the
order of apps in that sheet: on Gary's phone X sat behind AirDrop, Messages,
Mail and Facebook, reachable only by swiping the app row. Apple exposes no way
to pin an app or open a named share extension, so that swipe could not be
removed.

X now opens its composer directly, with the caption already written. The
picture cannot come with it — no URL can carry a file — so it travels two other
ways at once: it is put on the clipboard, and it is saved to Photos.
**In X: touch and hold inside the post and tap Paste.** The photo icon still
works if Paste does not offer it.

The clipboard normally holds the caption for the other platforms. It can hold
only one thing, which is why an earlier attempt at pasting the picture into X
came up empty — the caption was sitting on it. Now that the caption arrives
through the intent, the clipboard is free for the picture. X is the only
platform where that trade is available.

## Things that are correct, not bugs

- **Instagram gives you the picture and no caption.** Instagram has no way to
  receive text from another app. Paste it.
- **TikTok's "Add a catchy title" stays empty.** Same reason.
- **Facebook's caption must be pasted.** Facebook refuses prefilled text from
  third-party apps as a matter of policy.
- **X needs the picture pasted in.** The caption arrives already written; the
  picture is on your clipboard — touch and hold inside the post and tap Paste.
  It is in your Photos as well, so the photo icon works too. A URL cannot carry
  a file and X's composer is opened by URL, so one of the two has to be a
  paste. Confirmed working on Gary's iPhone, 2026-08-31.
- **Photo and video acts share the branded card, not your own photo.** The card
  is what carries the QR, so it wins.
- **Facebook cannot be tested in Expo Go** — the SDK is not linked there. Use the
  preview build.

## Notes for whoever picks up the code

- `src/components/ShareButtons.js` is the only share UI. Its header comment
  records which route each platform uses **and which approaches failed on a real
  device**. Read it before "simplifying" four buttons into one.
- `shareToX` has a similar note, and it is the most-rewritten function in the
  app — six routes have been tried. The share sheet is the only one that
  carries the picture, and it was still abandoned, because iOS buries X in the
  sheet and Apple gives no way to un-bury it. Read the comment before changing
  it back. `src/lib/xIntent.js` holds the URL building, with tests.
- `StoryCard.js` renders at `top: 0, left: 0` with 1px `overflow: hidden`. Fully
  off-screen views return blank captures on iOS. It looks like dead styling. It
  is not.
- `npm test` — 9 suites, 159 tests, verified green on 2026-08-31. Run before
  every push; a build passing is not the same as the suite passing. (An earlier
  handoff said 58; that counted only the two share suites.)
- `eas update` exports internally. Running `npx expo export` first leaves a
  `dist/` folder that can lock and break the update with `EBUSY`. Delete `dist`
  if that happens.
