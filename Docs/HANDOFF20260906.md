THE RESUBMIT BUTTON WAS GREYED OUT. This is the thing worth remembering. Apple
enables "Resubmit to App Review" only after the rejected item has been edited -
"Once you edit or remove all rejected items, click Resubmit to App Review from
the submission details page." A reply in the thread never enables it. If there
is ever another rejection, expect this.

THE EDIT MADE: one line appended to the end of the Notes field under App Review
Information -

    Resubmitted 6 Sept 2026.

The Notes field caps at 4,000 characters and had 43 free; that line uses 24.
Nothing else was touched. Build 97 is still the submitted binary.

Apple allows an item to be edited only ONCE before resubmission, so any future
edit of this kind should be made in a single pass.

HOW IT ACTUALLY WENT BACK: clicking the blue "Update Review" button at the top
of the version page resubmitted it directly. The greyed "Resubmit to App Review"
button on the submission page was never needed. Status moved straight to Waiting
for Review.

real status changes, so each one does generate an email. The label under
"iOS App" on the status page is still the fastest confirmation.

Contact Us -> App Review in App Store Connect, quoting the submission ID.

and you have tested the App Store link yourself. Release is the moment the link
